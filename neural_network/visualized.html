What happens each epoch?

  1. Compute Z₁ = XW₁ + b₁
  2. Apply ReLU to get hidden activations.
  3. Compute Z₂ = A₁W₂ + b₂.
  4. Apply Sigmoid to get probabilities.
  5. Measure binary cross-entropy.
  6. Backpropagate gradients.
  7. Update weights with gradient descent.

Core formulas

ReLU(z) = max(0, z)

σ(z) = 1 / (1 + e⁻ᶻ)

Loss = −mean[y log(a)
       + (1−y)log(1−a)]

W ← W − η ∂L/∂W
